# 3 · Desenvolupament del projecte

El projecte es desenvolupa mitjançant **sis fases consecutives**. Tot i que pots organitzar el teu treball amb certa flexibilitat, es recomana seguir aquest ordre per facilitar la implantació, la validació i la documentació de la infraestructura.

Cada fase inclou:

- **Objectiu**: què es pretén aconseguir.
- **Tasques**: treball que hauràs de desenvolupar.
- **Evidències**: informació que hauràs d'incorporar al dossier tècnic.
- **Autoverificació**: comprovacions recomanades abans de continuar.

## FASE 1 · Anàlisi de les necessitats

**Objectiu.** Comprendre les necessitats de l'empresa i definir els requisits que haurà de satisfer la infraestructura.

**Tasques**

- Analitzar l'escenari plantejat.
- Identificar les necessitats de l'organització.
- Determinar quins serveis seran necessaris.
- Revisar els paràmetres personalitzats del projecte.

**Evidències a incorporar al dossier**

- Anàlisi inicial.
- Necessitats detectades.
- Serveis que s'implantaran.
- Justificació de les decisions inicials.

**Autoverificació** — abans de continuar comprova que...

- [ ] Coneixes els requisits de l'empresa.
- [ ] Has identificat tots els serveis necessaris.
- [ ] Les decisions inicials estan justificades.

## FASE 2 · Disseny de la infraestructura

**Objectiu.** Planificar l'estructura completa abans d'iniciar la implantació.

**Tasques**

- Definir el domini.
- Dissenyar l'estructura d'UO.
- Definir usuaris i grups.
- Planificar els recursos compartits.
- Dissenyar les polítiques de grup.
- Preparar l'esquema general de la infraestructura.

**Evidències a incorporar al dossier**

- Esquema de la infraestructura.
- Organigrama del domini.
- Taules de configuració.
- Justificació del disseny.

**Autoverificació**

- [ ] L'estructura respon a les necessitats del projecte.
- [ ] Les UO estan justificades.
- [ ] Els recursos i permisos estan planificats.

## FASE 3 · Implantació

**Objectiu.** Construir la infraestructura planificada i configurar tots els serveis.

**Tasques.** Implanta tots els serveis necessaris segons els requisits del projecte. Entre d'altres, hauràs de desplegar i configurar:

- Windows Server 2022.
- Active Directory.
- DNS.
- DHCP.
- Unitats Organitzatives.
- Usuaris i grups.
- Recursos compartits.
- Permisos NTFS.
- Unitats de xarxa.
- GPO.
- Perfils d'usuari.
- Integració dels equips clients.
- Automatització mitjançant PowerShell.

**Evidències a incorporar al dossier**

- Captures de pantalla.
- Configuracions realitzades.
- Scripts desenvolupats.
- Explicació de les decisions adoptades.

**Autoverificació**

- [ ] El domini funciona.
- [ ] Els clients s'autentiquen.
- [ ] DNS resol correctament.
- [ ] DHCP assigna adreces.
- [ ] Les GPO s'apliquen.
- [ ] Els recursos compartits funcionen.
- [ ] Els perfils funcionen correctament.

## FASE 4 · Validació

**Objectiu.** Comprovar que tota la infraestructura funciona segons els requisits del projecte.

**Tasques.** Realitza les proves necessàries per verificar el correcte funcionament dels serveis implantats.

**Evidències a incorporar al dossier**

- Resultats de les proves.
- Captures.
- Explicació de les incidències detectades.
- Solució aplicada.

**Autoverificació**

- [ ] Tots els serveis han estat verificats.
- [ ] Les incidències detectades han estat resoltes.
- [ ] Les proves demostren el correcte funcionament.

## FASE 5 · Auditoria i millora

**Objectiu.** Analitzar críticament la infraestructura desenvolupada i identificar possibles millores.

**Tasques**

- Identificar punts forts.
- Detectar limitacions.
- Proposar millores tècniques.
- Justificar les propostes.

**Evidències a incorporar al dossier**

- Auditoria crítica.
- Propostes de millora.
- Conclusions tècniques.

**Autoverificació**

- [ ] Les propostes són viables.
- [ ] Les millores estan justificades.

## FASE 6 · Preparació del lliurament

**Objectiu.** Revisar tota la documentació abans del lliurament final.

**Tasques**

- Revisar el dossier tècnic.
- Organitzar les captures.
- Comprovar les justificacions.
- Completar les conclusions.
- Revisar els annexos.

**Evidències a incorporar al dossier**

- Dossier final.
- Annexos.
- Evidències organitzades.

**Autoverificació**

- [ ] El dossier està complet.
- [ ] Les captures són llegibles.
- [ ] Les taules estan completes.
- [ ] El document està revisat.
- [ ] El projecte està preparat per al lliurament.
