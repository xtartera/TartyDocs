# 2 · Objectius i requisits

## Objectiu general

Dissenyar, implantar, validar i documentar una infraestructura corporativa basada en Windows Server 2022, aplicant criteris professionals d'organització, administració i seguretat.

## Objectius específics

En finalitzar aquest projecte hauràs de ser capaç de:

- Analitzar les necessitats d'una organització abans de desplegar una infraestructura.
- Dissenyar una solució tècnica coherent amb els requisits plantejats.
- Implantar una infraestructura funcional basada en Windows Server 2022.
- Administrar de manera centralitzada els recursos i els serveis de la infraestructura.
- Verificar el correcte funcionament dels diferents serveis mitjançant proves objectives.
- Documentar el procés d'implantació i justificar les decisions tècniques adoptades.
- Aplicar bones pràctiques pròpies de l'administració de sistemes en entorns professionals.

## Què es valorarà durant el projecte?

Es valorarà especialment la teva capacitat per:

- Analitzar les necessitats del client abans de començar la implantació.
- Planificar una solució coherent i ben estructurada.
- Implantar correctament la infraestructura proposada.
- Verificar el funcionament dels serveis desplegats.
- Resoldre les incidències de manera autònoma.
- Justificar les decisions tècniques adoptades.
- Elaborar una documentació clara, ordenada i professional.

## Metodologia de treball

Aquest projecte s'ha dissenyat per simular el desenvolupament d'una implantació real d'infraestructura informàtica. Es recomana seguir una metodologia de treball ordenada, documentant el procés des del primer moment i validant cada servei abans de continuar amb la configuració de la resta de la infraestructura:

- Analitza les necessitats abans de començar qualsevol configuració.
- Planifica les decisions tècniques abans d'implementar-les.
- Valida cada servei immediatament després de configurar-lo.
- Documenta les configuracions, les incidències i les decisions adoptades durant tot el projecte.
- Mantingues el dossier tècnic actualitzat fins a la finalització del projecte.

## Què ha de ser capaç de fer la infraestructura?

La infraestructura haurà de permetre:

- Administrar centralitzadament usuaris, equips i recursos.
- Gestionar un domini corporatiu.
- Organitzar l'empresa mitjançant Unitats Organitzatives, usuaris i grups.
- Integrar equips Windows 11 al domini.
- Compartir recursos amb permisos adequats.
- Aplicar configuracions comunes mitjançant polítiques de grup.
- Facilitar l'accés als recursos corporatius mitjançant unitats de xarxa.
- Gestionar la persistència de la informació dels usuaris.
- Automatitzar tasques bàsiques d'administració amb PowerShell.
- Verificar el correcte funcionament de tots els serveis implantats.
- Elaborar una documentació tècnica completa de la infraestructura.

## Recursos disponibles

### Recursos tècnics

| Recurs | Descripció |
|---|---|
| Servidor | Màquina virtual amb Windows Server 2022. |
| Client | Màquina virtual amb Windows 11 Professional. |
| Configuració personalitzada | Cada alumne disposarà dels seus propis paràmetres (domini, IP, usuaris, equips, etc.). |
| Xarxa virtual | Infraestructura de xarxa necessària per al desenvolupament del projecte. |

### Recursos documentals

- Apunts i materials del mòdul.
- Documentació tècnica oficial de Microsoft.
- Recursos facilitats pel professorat.
- Documentació elaborada durant els projectes guiats.

### Eines de suport

Es permet utilitzar eines de suport tècnic, sempre que es faci de manera responsable: cercadors d'informació, intel·ligència artificial generativa, manuals tècnics, documentació oficial i comunitats tècniques especialitzades.

L'ús d'aquestes eines no eximeix de comprendre les configuracions implementades ni de justificar les decisions adoptades.

### Consideracions

Durant el projecte serà responsabilitat de cada alumne:

- Mantenir una organització adequada de la documentació.
- Conservar les evidències del treball realitzat.
- Validar totes les configuracions abans de considerar-les finalitzades.
- Elaborar un dossier tècnic que reflecteixi fidelment la infraestructura desenvolupada.
